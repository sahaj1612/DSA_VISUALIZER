# DSA Visualizer

DSA Visualizer is an Express and EJS based learning project that presents different data structures through a simple interactive interface.

## Tech Stack

- Node.js
- Express
- EJS

## Available Sections

- Array
- String
- Stack
- Queue
- Linked List
- Tree

## Run Locally

```bash
npm install
node route.js
```

Then open `http://localhost:8080`.

## Note

This project is focused on learning and visualization through a lightweight local web app.
